# Valea Obscura

Website multi-page pentru un boutique hotel fictiv din Carpați.

Deschide `home.html` într-un browser. Toate paginile folosesc `styles.css` și `script.js`.

## Sistem vizual

- Culori: Ink `#17201D`, Forest `#253B32`, Sage `#879A88`, Bone `#F3EFE6`, Paper `#FBF9F4`, Copper `#B86F47`
- Tipografie: Italiana (display), DM Sans (body)
- Spațiere: 8, 16, 24, 32, 48, 72, 112 px
- Grid: mobile-first; 2 coloane la tabletă, 12 coloane în galerie, 3 coloane pentru carduri

## Pagini

1. `home.html` — introducere și propunerea de valoare
2. `story.html` — istorie, filozofie și echipă
3. `rooms.html` — lista de camere
4. `room-detail.html` — template detaliu pentru Suita Panorama
5. `gallery.html` — galerie vizuală
6. `contact.html` — formular cu validare și stări empty / filled / error / success
